# 实现与验收计划

## 工程结构

仓库采用 Vite、React、Lucide 和 Playwright。每个方案有独立 React 模块，薄 HTML 入口只声明路由。

```text
boards/<board>/index.html
boards/<board>/components.html
src/moodboards/<IndependentMoodboard>.jsx
src/styles/moodboards.css
src/styles/components-01-03.css
src/styles/components-04-07.css
src/styles/components-08-10.css
public/previews/<board>.png
tests/moodboards.spec.js
```

## 独立实现门禁

1. 每套 Dashboard 和组件页面使用不同的根 class 与不同 DOM 结构。
2. 每套组件模块单独声明 `useState`、`useRef` 和外部点击处理，不通过公共 Hook 或 Store 共用状态。
3. 每套下拉菜单、日期选择、Checkbox、Radio、Toggle、上传、Tabs、Modal、Drawer、Toast 与动效单独实现。
4. 仅 `boards.js` 中的候选人、岗位、事件等静态演示数据和 Lucide 图标允许共享。
5. 生成页面前删除整个 `boards/` 目录，防止已淘汰方案残留在构建产物。

## 测试门禁

1. 十套方案 × 两类页面 × 三种视口，共 60 个响应式页面组合。
2. 十套独立交互用例逐一验证下拉框开关、外部关闭、选项确认、Checkbox、Modal 与专属动效。
3. 额外验证首页数量、真实预览图、十套独立根结构、图谱组件清除和废弃路由清除。
4. 自动测试后生成桌面、iPad、iPhone 的 Dashboard 与组件接触图，进行人工截图对比。
5. 发布前执行 `npm run build`、`npm run test:e2e`、`npm run capture:previews`、`npm run capture:review` 和 `git diff --check`。

## 发布门禁

1. 首页与全部 20 个子页面可访问。
2. GitHub Pages Action 构建成功。
3. 在线页面随机抽查 Dashboard、组件页、下拉、Modal 和动效。
4. 线上首页预览与对应 Dashboard 一致。
