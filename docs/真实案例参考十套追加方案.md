# Hunter SaaS 真实案例参考十套追加方案

## 1. 研究目标

第二轮 Moodboard 从真实优秀网站中提炼可迁移的设计原则，补充第一轮原创探索。它不是临摹练习，也不把营销落地页直接套到 Hunter 的业务界面中。

本轮共同边界：

1. 只借鉴信息组织、视觉节奏、动效逻辑、空间隐喻和材质语言。
2. 不复制参考网站的品牌资产、插画、字体文件、文案、页面代码和标志性构图。
3. 每套方案仍然以 Hunter 的岗位、候选人、公司、Mapping 和 Agent 任务为真实内容。
4. Aceternity UI 与 21st.dev 仅作为组件、动效和实现模式的参考库，不直接决定整页构图。
5. 每套方案均包含主要风格、组件系统、动效实验和 3D 空间四个独立页面。

## 2. 参考站点的分工

| 参考站点 | 本轮用途 | 使用边界 |
| --- | --- | --- |
| [Landing Love](https://www.landing.love/) | 观察完整页面动效节奏、3D 与品牌表达 | 不把高强度营销动效带入高频操作区 |
| [Landbook](https://land-book.com/design/website/saas) | 筛选成熟 SaaS、金融和 AI 产品的布局案例 | 不直接复刻着陆页模块顺序 |
| [Awwwards](https://www.awwwards.com/websites/blogs/) | 研究数据叙事、沉浸式探索与 WebGL 表达 | 可读性和任务效率优先于奖项式实验效果 |
| [One Page Love](https://onepagelove.com/) | 研究单页叙事、清晰节奏和特色视觉系统 | 不把所有业务压成一个滚动页面 |
| [Lapa Ninja](https://www.lapa.ninja/post/) | 研究企业产品表达、协作关系和资料库布局 | 仅采用适合后台产品的结构模式 |
| [Aceternity UI](https://ui.aceternity.com/components) | 参考状态按钮、时间线、视差、3D、拖拽等实现 | 禁止堆叠发光、渐变、光球等常见模板效果 |
| [21st.dev](https://21st.dev/community/components) | 比较同类组件的交互状态与响应式实现 | 选择经过业务验证的模式，不拼装社区组件墙 |
| [SiteInspire](https://www.siteinspire.com/) | 研究策展、档案、极简目录和展览式排版 | 不能牺牲表格、筛选和批量操作效率 |

## 3. 十套新增方向

### 11 动态信号账本 Kinetic Ledger

- **真实参考**：[Cash App Brand Guidelines / Landing Love](https://www.landing.love/sites/cash-app-design/)。
- **可迁移原则**：在严格秩序与局部爆发力之间形成张力；大字号承担状态，不靠普通指标卡堆叠信息。
- **Hunter 结构**：左侧为超大任务状态，中央为候选人信号账本，右侧为不断更新的证据票据；操作始终停靠在底部命令条。
- **视觉语言**：黑、白、荧光绿与安全橙；粗体数字、票据线、滚动字符和硬边框。
- **动效语言**：数字翻牌、证据票据插入、状态字切换、批量操作后的短促确认动画。
- **3D 方向**：任务信号形成旋转的账本柱和机械计数轮。
- **实现参考**：Aceternity Stateful Button、Text Flipping Board；21st 数字与状态组件。

### 12 物理智能遥测 Physical AI Telemetry

- **真实参考**：[Rerun / Landbook](https://land-book.com/design/website/ai)。
- **可迁移原则**：将复杂的时序数据、空间数据和运行状态放在同一个工程语境中，强调可观测而不是装饰。
- **Hunter 结构**：中央为候选人搜索与 Agent 的实时轨迹，左侧按来源分层，右侧按事件查看证据和错误。
- **视觉语言**：近黑底、冷灰信息、遥测橙、点云与时间刻度；不使用霓虹赛博朋克风格。
- **动效语言**：时间游标、事件脉冲、点云聚类和逐帧回放。
- **3D 方向**：LiDAR 式点云、轨迹环与候选人事件体。
- **实现参考**：Three.js Points/Line；21st Charts、Timelines、Progress。

### 13 可信机构台 Institutional Trust Desk

- **真实参考**：[Griffin 与 Adyen / Landbook](https://land-book.com/design/website/saas)。
- **可迁移原则**：通过明确的层级、审计痕迹和可解释动作建立信任，而不是依赖奢华装饰。
- **Hunter 结构**：顶部为当前业务承诺和风险，中央是审批账本，右侧是证据与责任归属；关键操作需显示结果影响。
- **视觉语言**：象牙白、墨蓝绿、砖红、清晰表格线和正式文书排版。
- **动效语言**：审计行插入、确认印记、字段差异比较和权限状态切换。
- **3D 方向**：层叠的档案板、验证环和可追踪的审批路径。
- **实现参考**：Aceternity Compare、Timeline；21st Tables、Dialogs、Badges。

### 14 AI 状态图册 AI State Atlas

- **真实参考**：[State of AI 2025 / Awwwards](https://www.awwwards.com/websites/web-design/?page=12)。
- **可迁移原则**：用章节、数据图形和注释把复杂研究结论组织成可浏览的报告，而不是普通 Dashboard。
- **Hunter 结构**：左侧章节索引，中央为岗位或行业研究图册，右侧为关键结论与来源；章节切换保留阅读位置。
- **视觉语言**：高对比报告排版、鲜明章节色、统计网格、地图式索引。
- **动效语言**：章节推进、图表分层出现、滚动注释、研究范围缩放。
- **3D 方向**：数据带、主题岛和研究结论构成可旋转图册。
- **实现参考**：Aceternity Sticky Scroll、Tracing Beam；21st Charts、Scroll Areas。

### 15 探索航程 Expedition Search

- **真实参考**：[Into The Amazon / Awwwards](https://www.awwwards.com/websites/blogs/)。
- **可迁移原则**：让长时间探索任务具有明确路线、里程碑和上下文，用户可以离开后继续理解任务进展。
- **Hunter 结构**：主界面是一条搜索航线，节点对应目标确认、数据源探索、候选人发现、证据验证和交付；边缘显示探索日志。
- **视觉语言**：地图纸、深森林绿、河流蓝、明亮标记色与细密坐标。
- **动效语言**：路径推进、航点展开、地图缩放、checkpoint 恢复和发现标记落下。
- **3D 方向**：低多边形地形、航路和研究站点。
- **实现参考**：Aceternity World Map、Tracing Beam；Three.js terrain primitives。

### 16 编译工作坊 Compile Workshop

- **真实参考**：[Cursor Compile / One Page Love](https://onepagelove.com/letters/88)。
- **可迁移原则**：用有组织的趣味性降低复杂工具的距离感，让任务像工作坊议程一样清晰可进入。
- **Hunter 结构**：搜索和匹配阶段表现为工作台上的工序，候选人是可移动工件，右侧为当日工序表和质量检查。
- **视觉语言**：纸张白、墨黑、钴蓝、亮黄、半调网点和机械标签；不使用儿童化插画。
- **动效语言**：工件入槽、键帽反馈、质量章、遮罩切换和任务编译完成。
- **3D 方向**：模块化机械键、传送带和检查框。
- **实现参考**：Aceternity Keyboard、Dither Shader；21st Stepper、Progress。

### 17 友好服务流程 Guided Service Story

- **真实参考**：[Eat Real Food / One Page Love](https://onepagelove.com/letters/82)。
- **可迁移原则**：通过友好但不幼稚的叙事降低新用户理解成本，流程说明与实际操作共存。
- **Hunter 结构**：当前任务占据主舞台，辅助角色、下一步和风险沿一条连续路径展开；复杂字段按需要出现。
- **视觉语言**：自然白、草绿、莓红、纸切轮廓和清晰图标，避免米色主导和大面积装饰插画。
- **动效语言**：路径接力、角色移动、步骤完成、提示浮现和错误回到对应节点。
- **3D 方向**：柔和的拱门、路径标记和任务令牌。
- **实现参考**：Aceternity Illustrations、Multi Step Loader；21st Onboarding、Steppers。

### 18 协作关系织网 Teamwork Fabric

- **真实参考**：[Atlassian Teamwork Graph / Lapa Ninja](https://www.lapa.ninja/category/corporate/)。
- **可迁移原则**：关系不只是一张图，还应显示人物、文件、任务与结果如何在团队中流动。
- **Hunter 结构**：按岗位、人员、证据和 Agent 四条泳道展示关系；跨泳道连接可追踪到责任人和结果。
- **视觉语言**：中性灰底、品牌蓝绿、关系色编码、清楚的泳道与对象锚点。
- **动效语言**：连接建立、泳道折叠、责任转移、协作批注到达和对象聚焦。
- **3D 方向**：多层织带连接不同业务平面，而不是复制第一轮的人才星图。
- **实现参考**：Aceternity Timeline、Animated Tooltip；21st Avatars、Lists、File Trees。

### 19 模式资料库 Pattern Library Browser

- **真实参考**：[Mobbin / Lapa Ninja](https://www.lapa.ninja/post/) 与 [Mobbin / SiteInspire](https://www.siteinspire.com/)。
- **可迁移原则**：用高密度资料浏览和强筛选支持大量候选人、公司、论文和证据的快速比较。
- **Hunter 结构**：左侧条件树、中部资料样本墙、右侧检查器；支持收藏、比较、批量选择和保存视图。
- **视觉语言**：中性白灰、严格缩略图比例、黑色文本和少量蓝/橙状态色。
- **动效语言**：筛选重排、缩略图聚焦、检查器切换、比较托盘吸附。
- **3D 方向**：资料面板构成可巡航的档案走廊。
- **实现参考**：Aceternity Focus Cards、Layout Grid；21st Galleries、Filters、Search Bars。

### 20 数字策展馆 Digital Curatorial Gallery

- **真实参考**：[Museum Department 与 Squarespace Foundations / SiteInspire](https://www.siteinspire.com/)。
- **可迁移原则**：通过策展式留白、目录和展签，让高价值候选人、研究成果和公司档案具有清楚的主次关系。
- **Hunter 结构**：顶部为展览目录，中央一次呈现一个重点实体，侧边展签承载证据、时间和关系；底部为可切换收藏序列。
- **视觉语言**：博物馆白、煤黑、深红、展签灰；大比例内容与细小元数据形成对比。
- **动效语言**：展品切换、目录定位、镜头平移、展签淡入和收藏序列滑动。
- **3D 方向**：空间展厅、信息展台和悬浮证据面板。
- **实现参考**：Aceternity Apple Cards Carousel、Lens；21st Galleries、Carousels。

## 4. 差异性 Review

| 编号 | 核心任务模型 | 主构图 | 主要视觉资产 | 与第一轮的区别 |
| --- | --- | --- | --- | --- |
| 11 | 信号与批量判断 | 大字状态 + 票据账本 | 计数轮、票据 | 不使用常规表格工作台 |
| 12 | 实时可观测 | 遥测画布 + 事件轨 | 点云、时间轨 | 不等同于指挥中心的大盘布局 |
| 13 | 审批与可信写入 | 审计账本 + 责任区 | 验证环、印记 | 更正式、更强调影响与审计 |
| 14 | 深度研究阅读 | 章节图册 + 注释 | 数据图、主题岛 | 与编辑部方向相比更偏数据报告 |
| 15 | 长任务探索 | 航线地图 + 航点 | 地形、路线 | 以 checkpoint 和旅程为核心 |
| 16 | 工序化处理 | 工作坊台面 + 工序表 | 键、传送带 | 趣味但仍是专业生产工具 |
| 17 | 新手引导与完成任务 | 连续服务路径 | 角色、拱门、令牌 | 不是静谧焦点的单一判断页 |
| 18 | 团队协作与交接 | 多业务泳道 | 织带、关系锚点 | 不使用全屏星图式关系画布 |
| 19 | 海量资料检索 | 条件树 + 样本墙 + 检查器 | 缩略图、档案走廊 | 重点是检索和比较效率 |
| 20 | 高价值成果呈现 | 展览目录 + 单一展品 | 展台、展签 | 强调策展和成果层级 |

Review 结论：十套新增方向的任务模型、页面骨架、视觉资产和动效语法均不同；同时与第一轮十套不存在仅换色或仅换字体的关系，可以进入实现。
