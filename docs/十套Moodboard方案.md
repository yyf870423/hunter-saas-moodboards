# Hunter SaaS 十套 Moodboard 方案（历史版本）

> 本文档已由《二十套科技猎头 Moodboard 重设计方案》替代，仅保留早期探索记录。当前实现不再包含 3D 页面，验收口径以新方案为准。

## 1. 目标与边界

本项目用于探索 Hunter SaaS 的产品视觉与交互方向。十套方案必须在信息架构、排版、组件形态、交互节奏、动效语言和空间隐喻上形成显著差异，不能只是替换色板。

共同产品背景：

- 核心用户是需要长时间、高频处理岗位、候选人、公司、论文、Mapping 和 Agent 任务的猎头与招聘顾问。
- 桌面端需要高信息密度和高操作效率；iPad 和 iPhone 需要保留完整能力，并通过折叠、抽屉和模式切换适应窄屏。
- 动效用于解释状态、关系和空间变化，不以装饰为目的。
- 3D 用于表达人才关系、组织结构、搜索空间或品牌气质；不能遮挡核心操作。
- 每套方案包括：主要风格页、完整组件页、动效实验页、独立 3D 空间页。

## 2. Skill 与工具使用原则

| 能力层 | 选择 | 用途 |
| --- | --- | --- |
| Moodboard 与品牌方向 | Taste Skill：`imagegen-frontend-web`、`brandkit`、`gpt-taste` | 形成差异化视觉方向，约束常见 AI 模板特征 |
| 设计审查 | Impeccable：`shape`、`critique`、`typeset`、`layout`、`animate`、`polish` | 检查层级、字体、布局、动效和视觉一致性 |
| 设计系统 | UI Skills：`create-design-md`、`improve-ui`、`fixing-motion-performance` | 固化设计 token、组件状态和动效性能边界 |
| Web 工程质量 | Vercel Agent Skills：`web-design-guidelines`、`react-best-practices`、`react-view-transitions` | 响应式、可访问性、性能与页面过渡 |
| 快速设计变体 | Google Stitch Skills：`generate-design`、`manage-design-system`、`react-components` | 适用于模块化和设计系统驱动的方向 |
| 3D 与高级动效 | Three.js、React Three Fiber、GSAP、Motion 专项 Skill | 关系网络、空间层级、滚动与状态动画 |
| 3D 资产 | Blender MCP | 仅在需要独特模型资产时使用，首轮以代码生成几何体为主 |
| 组件落地 | shadcn MCP、React Bits（参考） | 提供基础控件与少量标志性动效，不决定页面构图 |
| 视觉验收 | Codex Browser、Playwright | 多视口截图、交互检查、Canvas 非空与响应式验证 |

同一轮设计只允许一套 Skill 承担主艺术指导，其他 Skill 只用于审查、实现或性能检查，避免规则冲突。

## 3. 十套方向

### 01 精密作业台 Precision Desk

- **设计命题**：把 Hunter 设计成专业研究员的高密度作业台，强调扫描、比较和连续处理。
- **结构差异**：固定窄侧栏、中央表格/队列、右侧上下文检查器；桌面三栏，移动端转换为模式切换。
- **视觉语言**：瑞士平面设计、严格基线网格、窄体标题、黑白灰配安全绿色与信号橙。
- **组件语言**：直角或 4px 小圆角、紧凑表格、细分隔线、短标签、图标优先。
- **动效语言**：80–180ms，线性或快速减速；行选中、检查器切换、批量操作反馈。
- **3D 隐喻**：组织与候选人形成精密机械格架，节点沿规则轨道移动。
- **Skill 组合**：Impeccable `quieter/layout/typeset` + UI Skills `baseline-ui` + Vercel Web Guidelines。

### 02 编辑部研究桌 Editorial Intelligence

- **设计命题**：把岗位研究、公司洞察和候选人证据组织成可阅读、可批注的专业刊物。
- **结构差异**：上方刊头与章节导航，正文使用不对称多栏；操作工具沿页面边缘固定，不使用标准后台侧栏。
- **视觉语言**：编辑部排版、衬线标题、无衬线正文、纸张留白、脚注与边注体系。
- **组件语言**：文章段落、证据引用、旁注、档案表、版面式筛选条。
- **动效语言**：内容按阅读顺序渐进显现，栏位重排、批注展开、页签滑动。
- **3D 隐喻**：论文、专利、公司档案形成可翻阅的空间档案柜。
- **Skill 组合**：Taste `high-end-visual-design` + Impeccable `typeset/distill` + UI Skills `create-design-md`。

### 03 人才星图 Talent Constellation

- **设计命题**：关系和探索优先，主界面是一张持续生长的人才、组织、论文和岗位关系图。
- **结构差异**：全屏空间画布为主，左侧工具轨、底部时间轴、右侧按需展开的实体检查器。
- **视觉语言**：深色但不使用常见蓝紫渐变；炭黑、冷白、青绿信号和少量珊瑚色。
- **组件语言**：浮动工具轨、节点详情、关系筛选、空间图例、时间轨道。
- **动效语言**：节点聚合、路径追踪、镜头转场、关系脉冲、可控惯性。
- **3D 隐喻**：完整 3D 人才星图，支持旋转、缩放、聚焦和节点选择。
- **Skill 组合**：Three.js/R3F + GSAP + Impeccable `overdrive`，并用 Motion Performance Skill 做降级检查。

### 04 静谧焦点 Calm Focus

- **设计命题**：降低招聘工作的认知负担，一次只突出当前任务和下一步决定。
- **结构差异**：中央单任务工作区、顶部轻量全局导航、底部上下文队列；不展示持续存在的复杂侧栏。
- **视觉语言**：日式工业产品、低饱和白灰、墨绿与朱砂点色、大面积呼吸空间。
- **组件语言**：低对比边界、精确留白、分段式表单、渐进披露、聚焦模式。
- **动效语言**：柔和交叉淡入、共享元素转场、轻微弹簧但无弹跳感。
- **3D 隐喻**：数据石与路径庭院，状态变化表现为物体位置和光照变化。
- **Skill 组合**：Taste `minimalist-ui` + Impeccable `quieter/distill` + Vercel View Transitions。

### 05 招聘指挥中心 Command Center

- **设计命题**：突出自动化任务、异常处理和跨流程监控，适合同时管理大量岗位与 Agent。
- **结构差异**：顶部全局状态带、左侧任务频道、中部实时事件流、右侧异常与审批队列。
- **视觉语言**：深色控制室、暖白信息层级、红黄绿信号，不采用霓虹赛博朋克装饰。
- **组件语言**：状态矩阵、实时流、紧凑指标、命令菜单、告警抽屉、批量审批。
- **动效语言**：实时数字滚动、事件插入、告警扩散、进度轨迹、状态灯呼吸。
- **3D 隐喻**：自动化管线构成空间控制网络，任务在管道中流动。
- **Skill 组合**：Impeccable `bolder/animate/harden` + GSAP Timeline + Vercel React Best Practices。

### 06 人本关系所 Human Relations Studio

- **设计命题**：让候选人和联系人保持“人”的存在感，强调信任、沟通历史和关系路径。
- **结构差异**：以人物关系和沟通时间线为主，岗位与公司作为上下文；头像、关系路径和关键证据优先。
- **视觉语言**：现代人文主义、温暖白、墨色、鼠尾草绿与莓红；使用自然裁切人物素材和手工质感。
- **组件语言**：人物条目、关系卡、联系时间线、可信度、来源证据、协作批注。
- **动效语言**：关系线绘制、头像聚合、消息到达、时间线展开、轻柔视差。
- **3D 隐喻**：人物群落和关系桥梁，强调可到达路径而非抽象宇宙。
- **Skill 组合**：Taste `brandkit/imagegen-frontend-web` + Impeccable `delight/clarify` + Figma MCP（后续可编辑资产）。

### 07 包豪斯流程系统 Bauhaus Workflow

- **设计命题**：把流程、实体和动作压缩成大胆、可辨识的几何语法。
- **结构差异**：非对称模块网格、颜色承担功能分区、导航与内容嵌入同一版面。
- **视觉语言**：包豪斯与国际主义，原色控制使用，几何形状、粗细对比、明确黑线。
- **组件语言**：几何按钮、分区表格、流程圆点、粗线标签、模块化弹层。
- **动效语言**：几何变形、遮罩切换、方向性滑动、模块重排。
- **3D 隐喻**：基础几何体构成动态招聘流水线和组织模型。
- **Skill 组合**：UI UX Pro Max 风格检索 + Taste `industrial-brutalist-ui` + Impeccable `bolder/colorize`。

### 08 数据裁缝 Data Atelier

- **设计命题**：将 Hunter 定位为高端顾问服务的数字工作室，数据密集但克制、精致。
- **结构差异**：左侧细窄索引、中部大尺度工作面、右侧隐藏式工具柜；强调少量高价值信息。
- **视觉语言**：深墨、骨白、香槟金、冷银；细线、精密刻度和高级印刷感。
- **组件语言**：精致数据表、刻度型指标、材料化标签、低调弹窗、顾问摘要。
- **动效语言**：金属光泽掠过、精细描边、慢速视差、数字刻度展开。
- **3D 隐喻**：金属与玻璃数据柱、人才价值地形和精密仪器。
- **Skill 组合**：Taste `high-end-visual-design` + Impeccable `polish/typeset/quieter` + Motion。

### 09 动态蓝图 Kinetic Blueprint

- **设计命题**：把搜索策略、Mapping 和 Agent 计划表现为可执行的工程蓝图。
- **结构差异**：中央蓝图画布、可停靠属性面板、分层图纸导航、版本对比滑杆。
- **视觉语言**：工程蓝图但使用深青与暖灰而非纯蓝；网格、标尺、尺寸标注、手写批注。
- **组件语言**：图层面板、标尺输入、连接器、版本差异、执行节点、检查清单。
- **动效语言**：路径绘制、扫描线、图层装配、标注出现、镜头巡航。
- **3D 隐喻**：线框组织城市和岗位结构剖面，可在平面与空间模式间切换。
- **Skill 组合**：GSAP ScrollTrigger + Three.js Wireframe + UI Skills `fixing-motion-performance`。

### 10 自适应模块台 Adaptive Modules

- **设计命题**：让用户按任务组合工作区，同时保持模块边界、状态和响应式行为清晰。
- **结构差异**：可重排模块、上下文 Dock、命令中心；桌面自由组合，移动端自动转换为纵向任务栈。
- **视觉语言**：明亮中性底色，多色用于模块身份而非装饰；兼具软件工具和实体控制台质感。
- **组件语言**：可停靠面板、模块标题栏、命令面板、任务栈、可折叠数据区、拖动占位。
- **动效语言**：布局重排、共享元素、拖动吸附、模块折叠、命令面板过渡。
- **3D 隐喻**：模块积木构成岗位、候选人、公司和 Agent 的可组合工作流。
- **Skill 组合**：Google Stitch `manage-design-system/react-components` + shadcn MCP + Motion Layout + Impeccable `adapt`。

## 4. 共同页面与组件覆盖

每套组件页至少覆盖：

1. 主按钮、次按钮、危险按钮、文字按钮、图标按钮及全部状态。
2. 文本输入、搜索、多选、单选、日期范围、数字输入、开关、复选框、文件上传。
3. Tabs、侧栏、面包屑、分页、下拉菜单、命令菜单。
4. 状态标签、来源标签、风险提示、Toast、Banner、Tooltip。
5. Modal、Drawer、Popover、删除确认、处理中和错误状态。
6. 候选人、岗位、公司、论文、Agent 任务和 Mapping 节点条目。
7. 表格、列表、时间线、指标、进度条、迷你图表。
8. Loading、Skeleton、Empty、Error、Disabled、Permission-limited。

## 5. 响应式验收口径

- **16:9 宽屏**：以 1440×810 和 1920×1080 验证，不允许内容横向溢出或关键操作折行。
- **iPad**：以 1024×1366 和 834×1194 验证，复杂三栏切换为双栏或抽屉。
- **iPhone**：以 390×844 验证，完整保留操作能力，表格切换为可扫描列表或受控横向视图。
- 3D 页面必须在全部视口下非空、无遮挡，并提供 `prefers-reduced-motion` 降级。

## 6. 不采用的做法

- 不使用十套相同 DOM 结构只替换颜色。
- 不把每个区域都设计成悬浮卡片，不嵌套卡片。
- 不使用无意义紫蓝渐变、装饰光球、过度圆角和虚假数据大屏。
- 不为了展示 3D 而牺牲文本可读性、性能或核心任务操作。
- 不在 moodboard 中引入 Hunter 业务源码、凭据或用户数据。
