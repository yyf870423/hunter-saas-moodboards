# 实现与验收计划

## 工程结构

Moodboard 使用独立 Git 仓库，不引用或修改 Hunter 仓库代码。工程采用 Vite、React、Motion 和 Lucide。薄 HTML 入口只声明方案与页面类型，真实布局、组件和动效由对应方案的 React 函数与 CSS 命名空间实现。

```text
index.html
boards/<board>/index.html
boards/<board>/components.html
boards/<board>/motion.html
public/previews/<board>.png
src/
  data/
  components/
  layouts/
  styles/
scripts/
tests/
docs/
```

## 完成门禁

1. 首页展示二十张真实主页面截图，并可进入每套三个页面。
2. 六十个 Moodboard 子页面均有独立 URL，导航和返回路径完整。
3. 二十套主页面的布局模型不同。隐藏文字和配色后，仍能通过空间结构辨认大部分方案。
4. 二十套组件页使用独立结构，按钮、输入、选择、状态、业务条目和浮层不共用同一套可见模板。
5. 二十套动效页各有四种专属业务动效，触发方式、运动轨迹和反馈结果与概念一致。
6. 桌面、iPad 和 iPhone 均不得出现横向溢出、运行错误、文字遮挡或关键操作丢失。
7. Playwright 覆盖 20 套方案 × 3 类页面 × 3 种视口，并额外验证首页、独立结构、动效触发和已删除路由。
8. GitHub Pages Action 构建通过，公开 URL 和六十个子页面可访问。
