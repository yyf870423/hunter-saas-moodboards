# 实现与验收计划

## 工程结构

Moodboard 使用独立 Git 仓库，不引用或修改 Hunter 仓库代码。工程采用 Vite、React、Three.js、Motion 和 Lucide；页面使用共享运行时、共享业务组件和二十套独立配置。

```text
index.html
boards/<board>/index.html
boards/<board>/components.html
boards/<board>/motion.html
boards/<board>/spatial.html
src/
  data/
  components/
  layouts/
  scenes/
  styles/
tests/
docs/
```

## 完成门禁

1. 首页能浏览二十套方案，并可进入每套四类页面。
2. 八十个 moodboard 子页面均为独立 URL，导航和返回路径完整。
3. 二十套主页面的布局模型不同，而不仅是主题变量不同。
4. 组件页覆盖方案文档中的组件和状态清单。
5. 动效页的触发控件可操作，并支持减少动态效果。
6. 3D 页使用独立场景，桌面、iPad、iPhone Canvas 像素检查非空。
7. Playwright 覆盖 1440×810、1024×1366、390×844 三类视口。
8. GitHub Pages Action 构建通过，公开 URL 可访问。

## 第一轮执行结果

- 已实现 10 套主要风格页、10 套组件页、10 套动效页和 10 套 3D 空间页。
- 十套主要页面使用十种独立信息架构，不通过同一 DOM 换色生成。
- 组件页覆盖正常、加载、空、错误、禁用和权限受限状态。
- 动效页每套覆盖 12 类可操作业务动效。
- 3D 页面使用 10 个不同场景，并移除远程材质依赖。
- Playwright 共执行 123 项测试；122 项首轮通过，1 项测试定位歧义修正后通过。
- 已覆盖 1440×810、834×1194、390×844 三种视口，以及 Canvas 像素差异检查。

## 第二轮执行结果
